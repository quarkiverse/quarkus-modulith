[.description]
--
Whether to apply module-specific Flyway migrations to the default datasource, the counterpart of `spring.modulith.runtime.flyway-enabled`. The migrations in the `__root` folder of each Flyway location run first with the configured history table, then, in module dependency order, those in the folder named after each module, with a history table named after the configured one plus an underscore and the module name (for example `flyway_schema_history_order`). In a module test only the modules the test starts are migrated. Takes effect at build time.
